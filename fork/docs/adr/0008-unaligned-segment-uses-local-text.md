# ADR-0008：Dropline 段對齊不可信時，該段定稿用本機文字

- 狀態：已接受（Derek，2026-11-25）
- 範圍：Mac 的 Meetings
- 依據：ADR-0003、ADR-0005

## 背景
Dropline 不回傳時間。Hex 先讓本機流程完成兩軌合併與回音抑制，再把留下的本機紀錄換成字元對齊後的 Dropline 文字，借用本機的時間。兩邊文字差異太大時，對齊不可信。

## 決定
對齊比例低於門檻（先設 0.4）的成功段，定稿這段用本機文字（已轉繁體），不使用該段的 Dropline 文字。

## 考慮過的做法
- 保留 Dropline 文字為一條 2–3 分鐘的紀錄：發言順序變粗，麥克風段可能含對方的話，Stop 後的 Copy new 可能整段重貼。

## 影響
- 「Dropline 成功但定稿用本機文字」多了一種情況，介面沒有標示。
- 能計算對齊比例的段，比例以數字寫進 log，之後依真實會議調整門檻。
